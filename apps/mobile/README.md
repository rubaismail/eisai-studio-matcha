# Mobile app (Flutter)

Shows the same menu as the website by calling the same API. It never talks to MongoDB directly.

## Run it

1. Install Flutter (stable, 3.35 or newer) and run `flutter doctor` until it's happy.
2. Start the API from the repo root: `npm run dev`.
3. In this folder:

   ```sh
   flutter pub get
   flutter run                                                    # iOS simulator, desktop, or Chrome
   flutter run --dart-define=API_URL=http://10.0.2.2:4000/api     # Android emulator
   ```

4. Before opening a PR: `flutter analyze` and `flutter test`.

## Where your code goes

| Folder | Put this here | Example |
| --- | --- | --- |
| `lib/screens/` | One file per screen. | `login_screen.dart` |
| `lib/widgets/` | Pieces used on more than one screen. | `menu_item_tile.dart` |
| `lib/services/` | Functions that call the API. Screens never call `http` directly. | `auth_service.dart` |
| `lib/models/` | Dart classes for API data, with `fromJson`. Must match SwaggerHub. | `user.dart` |
| `lib/config.dart` | The API address. | |
| `test/` | Widget and unit tests, named `<file>_test.dart`. | |

`android/`, `ios/` and `web/` are generated by Flutter. Leave them alone unless you're changing app icons, permissions or the app name.
